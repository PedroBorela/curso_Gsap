## 🛠️ Tecnologias Utilizadas

- **React 19**: Biblioteca para construção de interfaces.
- **GSAP**: O padrão da indústria para animações JavaScript.
- **Tailwind CSS**: Framework CSS utilitário para estilização rápida.
- **Vite**: Build tool extremamente rápida para o desenvolvimento.
- **React-use**: Coleção de hooks essenciais para React.

---

## 🚀 Como Rodar a Aplicação

Siga os passos abaixo para executar o projeto localmente:

### 1. Clonar o repositório
```bash
git clone <url-do-repositorio>
cd curso_Gsap
```

### 2. Instalar as dependências
```bash
npm install
```

### 3. Executar o servidor de desenvolvimento
```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173`.

## 📝 Histórico de Comandos (Setup Inicial)

Para fins de documentação, estes foram os comandos utilizados na inicialização do projeto:

```bash
# Inicialização do Vite
npm create vite@latest ./

# Instalação básica
npm install

# Setup Tailwind CSS
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p

# Bibliotecas Adicionais
npm install react-icons --save
npm install @gsap/react gsap
npm i react-use
```
